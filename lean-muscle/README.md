# 薄肌个人发展教练 · lean-muscle skill

一个可复用的 AI 技能（Agent Skill）：把「改善」从一次性激励，变成**可反复执行、可修正的过程**。

基于三期视频内容整理——《如何练出薄肌》《你需要黄毛思维》《对话孙宇晨：AI 时代个人发展》——提炼成一套覆盖**身体、思维、关系、事业与 AI 使用**的个人发展框架。

---

## 六大模块

| # | 模块 | 做什么 | 需要的输入 |
|---|---|---|---|
| 一 | 每日健康指南 | 解读饮食/训练，输出日报 | 饮食照片、训练内容、睡眠 |
| 二 | 健身辅助 | 基线判断 + 训练饮食方案 + 真实视频案例 | 身高/体重/体脂、目标、训练数据 |
| 三 | 思维提升 | 职业与决策建议 + 搜索博主/视频链接 | 职业信息、目标领域、资源限制 |
| 四 | 自我提升记录 | 连续记录 + 四问复盘 + 阶段总结 | 每日记录、健康数据 |
| 五 | 生活与关系 | 薄肌+黄毛思维框架、关系与性压抑 | 具体困扰 |
| 六 | AI 使用与赋能 | 怎么用 AI、怎么给生活赋能、怎么写 skill | 想用 AI 做的事、已有工具 |

## 核心理念

> 固定记录 → 观察变化 → 调整做法 → 再记录

每次复盘只回答四问：① 目标是什么 ② 实际发生了什么 ③ 哪里要修正 ④ 下一步做什么。

五条原则：健康是长期一切的前提 · 自主性与开放性并存 · 记录服务于反馈 · 探索后要行动 · 成长留恢复空间。

## 安装

### DeepSeek Harness（DSH）

```bash
# 全局安装（所有工作区可用）
cp -r lean-muscle ~/.agents/skills/

# 或某个项目（仅该项目可用）
cp -r lean-muscle <项目目录>/.agents/skills/
```

Windows PowerShell 用 `Copy-Item -Recurse lean-muscle <目标目录>`。

### Claude Code

```bash
# 个人级（所有项目）
cp -r lean-muscle ~/.claude/skills/

# 项目级
cp -r lean-muscle <项目目录>/.claude/skills/
```

### 其它 agent（通用）

1. **有 skill / 规则目录的**：放进对应目录（如 Cursor 的 `.cursor/rules/`）。
2. **没有目录机制的**：把 `SKILL.md` 正文（frontmatter 之后的内容）贴进系统提示 / 自定义指令，或作为上下文附件。
3. **只想用一个文件**：把 `SKILL.md` 与 `references/` 三个文件合并成一个 markdown 使用。

## 使用模板（复制即用）

### 万能模板

> 我的目标是 **____**。当前情况是 **____**（数据/现状），限制是 **____**。请先指出我缺的信息，比较几种做法，再给我一个本周能执行的具体动作；把**已知事实 / 你的假设 / 需要我验证的部分**分开说明。

### 六模块开场白

| 模块 | 示例 |
|---|---|
| ① 每日健康 | 「今天午餐吃了〔照片〕，练了〔俯卧撑 4 组 / 慢跑 30 分钟〕，睡了 6 小时，帮我出今日健康日报。」 |
| ② 健身辅助 | 「25 岁，178cm / 70kg，体脂约 18%，目标是薄肌（体脂降到 13%）。每周去健身房 2 次、动作不规范。给我：①基线判断 ②训练+饮食方案 ③适合我的视频案例。」 |
| ③ 思维提升 | 「我在〔行业/岗位〕，想转〔目标领域〕，现状是〔资源/限制〕。帮我搜这个领域值得关注的博主和经典视频，附链接，再比较几条路径给建议。」 |
| ④ 自我提升 | 「这是本周记录：〔训练/饮食/心态/作品〕。帮我用四问复盘，输出『保留什么 / 调整什么 / 下一步』。」 |
| ⑤ 生活关系 | 「最近〔具体困扰〕。按薄肌+黄毛框架帮我分析，别只给结论，给我一个可执行的下一步。」 |
| ⑥ AI 使用 | 「我想用 AI 帮我〔做X〕，手头有〔工具/预算〕。告诉我怎么起步、用哪个工具、注意什么。」 |

## 使用指南（最佳实践）

### 触发方式
- **直接说主题**：说「帮我看看今天饮食」「我想减脂」，命中 `description` 会自动加载。
- **手动调用**：输入 `/lean-muscle` 再跟问题。

### 让对话「接得上」
1. **用数据代替感受**：说「深蹲 60kg 5×5」，不说「练得不错」——前者才能反馈。
2. **维护累计记录**：把体重、训练、饮食、复盘存到一个文档，下次直接说「继续这份记录」或贴最新数据，不要每次重新自我介绍。
3. **小步试验**：别要求一步到位的完美方案，要一个本周能完成的动作，做完带结果回来调整。

### 常见误区
- ❌ 只说「我想变瘦」→ 会被追问。✅ 带上身高体重体脂 + 目标 + 时间。
- ❌ 每次从头介绍自己 → 浪费。✅ 复用上次的文档/记录。
- ❌ 要「保证有效」的答案 → 本技能会诚实区分「事实/假设/待验证」。

## 安全与边界

- 健康/健身建议**不替代**医生、教练、营养师；不提供医疗诊断或补剂剂量承诺；疑似疾病、伤痛、极端节食建议就医。
- 投资与行业趋势观点需注明出处与不确定性，**不构成投资建议**。
- 涉及关系/他人时尊重个体差异，主动社交须强调**尊重、边界与同意**。
- 引用视频/资料给出真实链接与归属；无法核实的标注「待核实」。
