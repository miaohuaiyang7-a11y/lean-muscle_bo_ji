# 三期视频方法论要点与边界条件（source notes）

> 对应文档《三期视频内容与综合总结》。正文按主题转述并保留观点归属，用于回答用户关于健身、关系/自主性、职业与 AI 的具体问题时引用；原始数据以原视频为准。

## 一、薄肌训练（邵艾伦）

- 「薄肌」= 适度肌肉量 + 较低体脂形成的外观。
- 训练：每周 3 次力量训练，以深蹲、硬拉、卧推、推举等**复合动作**为基础；记录并逐步提高表现。
- 饮食：重点是**蛋白质与总热量**；偏瘦缺肌肉、腰腹脂肪多，摄入方向不同。
- 其他：蛋白粉、肌酸、步行、长期坚持。
- 可迁移的行为原则：**固定训练、留下记录、观察变化、再调整**。
- 边界：体脂目标、补剂剂量、见效时间属作者经验性方案，不能直接当个人健康结论。

## 二、黄毛思维（邵艾伦，关系与自主性）

- 区分「客观条件」（外貌/财富/事业）与「相处时被感受到的」自信、独立、边界。
- 无原则迎合、因回复速度焦虑，会让关系围绕对方认可运转。
- 主张保有事业、兴趣、社交与自己的节奏；刻意装冷淡不能代替稳定的自我。
- 可以关心对方，也接受对方有离开的自由。
- 边界：SMV 高低框架与性别概括是作者的解释方式；关心、道歉、合理妥协不等于失去自主性。

## 四、需要保留的条件（引用时务必区分）

| 材料中的表达 | 综合理解时保留的条件 |
|---|---|
| 百分之百相信 AI | 多模型一致仍不等于正确；重要结论查来源并观察现实反馈 |
| 用薄肌拿下健康 | 「寿命百分制」不是医学量表；肌力、有氧、减少久坐均需关注 |
| 用价值高低解释关系 | 个体差异、双方沟通与责任不能被一个分数替代 |
| 认知决定结果 | 资源、机会、运气、制度条件同样影响结果 |
| 从技术趋势推导投资机会 | 技术有用途 ≠ 某项资产值得买；嘉宾也有业务立场 |

## 五、四周小试验模板（可直接套用）

| 阶段 | 重点做法 | 留下的成果 |
|---|---|---|
| 第一周 | 选一个当前问题，写下目标、现状、时间与预算限制 | 一页现状说明 + 少量相关记录 |
| 第二周 | 调查三种路径，请 AI 整理依据、成本与不确定性 | 一张比较表 + 一个优先试验 |
| 第三周 | 集中完成一个可展示/可测试的小版本 | 试玩片段/短视频/章节草稿或其他成品 |
| 第四周 | 比较结果与目标，检查哪里有效、哪些假设不成立 | 一次复盘 + 下一轮保留或调整的做法 |
