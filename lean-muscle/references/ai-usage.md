# AI 使用与生活赋能（详细指南）

> 对应文档第三期访谈（孙宇晨 × 邵艾伦）关于 AI 的部分，并补充「如何写 skill」的说明。方法是经验性建议，AI 输出需自行核实。

## 一、使用 AI 的心法（先于工具）

1. **先记录，再让 AI 分析**：把饮食照片、训练视频、睡眠数据、目标与限制交给 AI，形成连续日报；历史资料保存为可迁移文档，让下一次分析接得上上一次，而不是每次重新介绍自己。
2. **从低成本起步**：资源少先用负担得起的工具，记录现状、目标与限制，请 AI 提方向并持续调整。
3. **多模型对比**：比较多个模型的回答，而不是只保留一段孤立聊天；多模型一致 ≠ 正确，重要结论要查来源并观察现实反馈。
4. **决策前「先探图」**：让 AI 搜集与对照信息、扩大选项、建立比较标准；AI 减少视野过窄，但不提供「保证选对」的公式。
5. **让知识可被机器处理**：把资料、数据、判断形式化、结构化，方便之后复用、检索与组合。

## 二、各种 AI 的用途（按场景）

| 场景 | 用什么 | 说明 |
|---|---|---|
| 通用问答/写作/总结/头脑风暴 | 对话式 AI（大模型） | 先给背景与目标，让输出结构化 |
| 饮食照片、训练动作图 | 图像识别 AI | 读图后估算营养/判断动作，再给建议 |
| 身体数据、表格分析 | 本地 Python（pandas / XlsxWriter） | 体重/体脂趋势、训练量统计 |
| 文档产出 | office-docx / office-pptx / office-xlsx | 生成 .docx / .pptx / .xlsx 存档 |
| 信息搜集 | web_search / web_fetch | 查博主、经典视频、行业资料 |

## 三、AI 如何给生活赋能（落点）

- **健康**：饮食照片 → 营养缺口；训练数据 → 反馈与调整；睡眠/活动 → 恢复建议。
- **事业/决策**：探图、信息对照、多选项比较。
- **自我提升**：日报、周报、四问复盘、阶段总结。
- **创作**：把学习与体验转成可展示成果（游戏、视频、写作），用真实反馈迭代。

## 四、如何写一个 skill（沉淀方法）

当某种做法已多次产生稳定结果，就把它做成 skill，才能复用经过验证的方法。

**格式**：
- 目录 bundle：`<name>/SKILL.md`，或平铺文件 `<name>.md`，放在扫描根目录（项目 `.agents/skills/` 或用户 `~/.agents/skills/`）。
- 文件以 YAML frontmatter 开头：
  - 必填 `name`（kebab-case，小写连字符）、`description`（说明何时使用）；
  - 可选 `whenToUse`、`metadata`、`disable-model-invocation`、`user-invocable`。
- 正文是 markdown 指令：先写核心理念，再分模块给步骤，最后写安全边界与输出规范。

**要点**：
- 正文保持精简（约 8192 字符内），参考资料放 `references/` 按需读取。
- 先保留真实样例（成功的输入、步骤、产出），skill 才能复用经过验证的方法。
- 触发方式：任务命中 `description` 时系统自动加载，也可用 `/name` 手动调用。

**示例**：本 skill（`lean-muscle`）本身就是一个例子——`SKILL.md` + `references/`（fitness-videos.md、source-notes.md、ai-usage.md）。
